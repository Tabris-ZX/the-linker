# 织链 游戏玩法demo

## 名词解释

色点: 就是有颜色的实体点,每个id有两个(即一对)

理论上: 假定玩家标记的都是正确的情况下

## 具体规则

### 目标

**初始时,每个id的色点只会显示一个,我们需要通过推理找到每个id所对应的另一个色点的位置**

### 流程 

玩家可以在地图上任意画出线段和标记自认为的隐藏色点的位置

游戏右侧有提交按钮,每次**提交**后,系统会检查玩家所标记的色点与正确位置是否匹配

#### 提交

每次提交后,系统会反馈每个已标记色点的对错情况,系统每次检查只基于**玩家已标记的色点**检查

若玩家有标记错误的色点,则会产生罚时,暂定罚时为 (x*(39+x)/2)秒(单独写一个罚时计算函数,后面可能会调整罚时计算),x为错误色点数

### 胜利判定

玩家点击了提交后,如果所有的隐藏色点位置全部找对了,即为胜利

### 提示(暂定)

存在于地图的左侧和上侧,会显示当前列/行**理论上**还有多少隐藏色点存在

每次玩家标记后,都会动态调整当前行/列的理论色点数
