# 游戏目标

## 将所有同色的色点相连,且填满棋盘上的所有格子算通关

# 规则说明

1. 每对色点必须连接成一条完整路径
2. 不同颜色的路径不能相交,不能重叠
3. 每个格子只能被一条路径占用

# 操作方式
- 从一个颜色端点出发,**拖动**即可绘制路径
- 反向拖回可撤回线段
- 双击色点可以清除与该点相连的整条路径

# 关卡编辑(移动端不支持)

## 可以设计地图上传,审核通过后即可上线正式关卡

在编辑页编辑出你所设计的地图及其解法.
生成对应json后点击右上角项目链接提issue

**标记模式:** 编辑出地图正解路线 
**移除模式:** 移去模板地图的某条边
